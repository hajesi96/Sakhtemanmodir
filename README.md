# پروژه اندروید مدیریت ساختمان

**نسخه فعلی: 1.2.1**

- زبان: Kotlin
- رابط کاربری: Jetpack Compose / Material 3
- پایگاه داده محلی: Room (اطلاعات روی همان دستگاه ذخیره می‌شود)
- شروع اولیه با ۱۶ واحد
- مدیریت واحدها، مالک/مستأجر، شماره تماس و تعداد نفرات
- ثبت دریافت با نوع «هزینه آب» یا «شارژ ماهیانه» و تاریخ شمسی
- تنظیمات نام ساختمان و شیوه نمایش
- مدیریت دریافت‌ها و هزینه‌ها
- ثبت قبض آب ماهانه و محاسبه سهم هر واحد بر اساس تعداد ساکنان ثبت‌شده
- ذخیره تعداد ساکنان و سهم هر واحد در زمان ثبت قبض؛ تغییرات بعدی ساکنان، گزارش ماه قبل را عوض نمی‌کند
- گزارش ماهانه و خروجی فایل XLSX راست‌به‌چپ شامل خلاصه مالی، واحدها، ساکنان، سهم آب، دریافت‌ها و هزینه‌ها

## ساخت APK
1. پوشه پروژه را در Android Studio باز کنید.
2. JDK 17 و Android SDK Platform 35 را نصب/انتخاب کنید.
3. اجازه دهید Gradle Sync کامل شود.
4. از مسیر Build > Build Bundle(s) / APK(s) > Build APK(s) خروجی بگیرید.

مسیر معمول خروجی: `app/build/outputs/apk/debug/app-debug.apk`

## نکات نسخه ۱.۲.۱
- فرم دریافت‌ها بدون فیلد شرح و با دو نوع دریافت مشخص
- نمایش نام ماه شمسی و تاریخ شمسی در فرم دریافت
- واحدهای اولیه فقط در اجرای نخست ساخته می‌شوند؛ حذف همه واحدها باعث ساخته‌شدن دوباره آن‌ها نمی‌شود
- تنظیمات نام ساختمان، نمای فشرده و یادآوری‌ها

## نکات نسخه ۱.۱
- اطلاعات در پایگاه داده محلی همان گوشی ذخیره می‌شوند.
- برای هر ماه قبض آب جداگانه ثبت می‌شود.
- سهم آب متناسب با تعداد ساکنان هر واحد محاسبه می‌شود و اختلاف گرد کردن به آخرین واحد دارای سکنه تخصیص می‌یابد تا جمع سهم‌ها دقیقاً برابر مبلغ قبض باشد.
- خروجی اکسل ماهانه شامل جزئیات تخصیص قبض آب است.
- همگام‌سازی ابری و اپلیکیشن همسایه هنوز پیاده‌سازی نشده‌اند.

## وضعیت ساخت
این محیط Android SDK و Gradle اجرایی در دسترس ندارد؛ بنابراین سورس به‌روزرسانی شده، اما APK در این محیط کامپایل و آزمایش دستگاهی نشده است.
